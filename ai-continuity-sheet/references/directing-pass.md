# 导演会诊（为表演列和剧情大纲列做准备）

在填写「微表情情绪指导」「动作表演指导」「剧情大纲」三列之前，对每个 SC 做一次内部导演会诊。规则已内置，无需安装其他 skill。会诊结果只在内部使用，不输出到表格。

## 1. 场次导演命题（每个 SC 一次）

先回答四个问题，压成一句导演命题：

- 这场戏去掉后，故事损失什么？
- 这是谁的场，观众跟谁感受？
- 人物关系或力量对比在哪个刺激点翻转？
- 哪个瞬间必须被看见，而不只是被台词说明？

示例：表面是典当木簪，真正要拍的是苏老太第一次意识到现代规则，并决定护住传家物。

## 2. Beat 划分

按戏剧力量变化拆：进入、试探、揭示、反应、选择、余波。每个 Beat 写清：

- 进入状态
- 触发点（对方刚做了什么）
- 身体或注意力变化
- 退出状态

重要信息揭示后必须留承接：停顿、目光、呼吸变化、他人反应或动作中断。

## 3. 逐 P 表演谱

每个 P 的主体角色内部整理以下字段，再交给子 skill 压缩成表格值：

| 字段 | 交给 |
|------|------|
| 刺激 → 先变化的通道（眼/呼吸/重心/手/声音） | micro-expression-director |
| 起始姿态 → 主要叙事动作 → 退出状态 | action-performance-director |
| 本 P 的事件 + 力量变化 | scene-synopsis |

规则：

- 一拍只让一个通道先变化，不要所有通道同时变
- 角色说台词时正在做什么，而不是摆什么表情
- 目光看向具体对象，何时移开要有原因
- 删掉情绪形容词后指令仍然可拍、可看、可验收
- 避免 AI 套路：提前反应、无对象说话、重复手势、嘴脸同频

## 4. 抽象词改写为可见行为

| 抽象词 | 可见行为 |
|--------|---------|
| 紧张 | 搓指、呼吸变浅、目光寻找出口 |
| 隐瞒 | 回答前停顿、避开目光、句尾收声 |
| 权力感 | 不急于回答、少动作、先观察再开口 |
| 崩溃后平静 | 呼吸逐渐下降、身体收回、目光重新聚焦 |
| 警觉 | 停步、先扫视空间、身体保持撤退方向 |

## 5. 不越权

- 不新增剧本中不存在的剧情事件、人物或道具操作
- 剧本本身不合理时，技术性问题（笔误、方位矛盾）可直接修正，剧情层面问题只提醒用户，不擅自改写
- 状态必须来自情境和前因，不来自服装或标签（穿睡衣≠困倦，带伤≠始终虚弱）
