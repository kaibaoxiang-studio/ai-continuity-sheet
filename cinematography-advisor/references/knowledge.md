# 摄影字段规则

来源：jimeng-storyboard-v3/references/output-format.md + state-continuity.md + common-performance.md

## 景别体系

每拍必须显式给出景别。景别分三类层级：

| 层级 | 包含景别 |
|------|---------|
| 中远景/全景类 | 远景、全景、大全景 |
| 中景/中近景类 | 中景、中近景、过肩 |
| 近景/特写类 | 近景、特写、大特写、怼脸 |

**硬约束**：每个 P 段至少覆盖两类景别层级；禁止连续三个节拍使用同一景别层级（允许连续两拍相同）。

## 景别与表演通道对应

按景别选择可拍内容：

- 怼脸/大特写：只写脸、眼神、下半脸和呼吸
- 近景/特写：以通道 A（微表情）为主，补手和肩
- 中景：先写通道 B（姿态重心），再补可见微表情
- 全景/远景：写整体姿态、步态和轮廓，不写看不清的细微表情

## 文戏镜头规则

文戏默认静多动少：固定镜头、慢推、慢拉、慢摇、慢跟和过肩反打。

- 对白和表演镜优先固定机位与硬切
- 转场、建立或揭示镜允许缓慢位移
- 固定机位通过角度、构图、焦点、景别和主体数量变化避免扁平
- 用焦点转移替代不必要的推拉
- 决定性情绪才使用怼脸特写，不让每段都以怼脸收尾

## 景别软路径（按叙事功能选策略）

| 叙事功能 | 可选镜头策略 |
|---------|------------|
| 建立关系 | 双人中景或过肩关系 → 接收方反应 → 关系落点 |
| 权力变化 | 受压方视角/构图 → 权力方动作或台词 → 新强弱关系 |
| 信息揭示 | 道具或视线落点 → 说话方 → 接收方反应 |
| 人物移动 | 运动起点 → 跟随或遮挡转接 → 新位置关系 |
| 主观体验 | 主观视角或局部感知 → 生理反应 → 客观关系回落 |
| 冲突爆点 | 攻防关系 → 命中或反转 → 结果与余波 |

## 运镜要求

每次运镜必须写清：
1. 叙事触发（为什么动）
2. 路径或速度变化
3. 停止构图（落在哪里）

没有明确动机时保持锁定或有限摇移，不用无目的推进、环绕和手持制造"电影感"。

## 镜头方位精度

涉及双人关系、过肩、床边、门边、遮挡、前后景、视线反打或人物移动时，首次建立机位以及每次换机位都要交代：

1. **摄影机位置**：相对场景固定物或人物位于哪一侧、哪一端
2. **摄影机高度与俯仰**：高度参照物及平视/俯拍/仰拍
3. **拍摄方向**："从哪里朝哪里拍"或"沿固定物A至固定物B方向拍"
4. **前景归属**：写清谁的哪一侧身体或哪个物件进入前景，以及虚实关系
5. **画面落位**：关键主体的画面左/中/右

以下词语不能裸用（必须在同句补全参照信息）：`肩侧`、`肩后`、`过肩`、`床侧`、`床边`、`侧面`、`一旁`、`近旁`、`画面边缘`、`靠近`

## 镜头运动补充规则

来源：知识库/导演相关/总导演/分镜导演.html + 镜头导演.html

### 推镜头 vs 变焦必须区分

| 类型 | 背景变化 | 视差 | 效果 |
|------|---------|------|------|
| 推镜头（Dolly In） | 有视差位移 | 有 | 电影感、空间纵深 |
| 变焦（Zoom） | 只有大小变化 | 无 | "PPT动画感" |

写错会直接导致画面缺乏电影感。

### 镜头运动描述格式

感性形容词（"画面震撼"）对视频模型无效。必须改为结构化描述：

**Subject（主体）/ Action（动作）/ Camera（镜头运动）**

剔除氛围词、风格词和"电影感"等观后感式描述。

### 三层动态镜头公式

一个完整运动镜头需要四层信息：

```
第一层：主体动作（移动方向+速度+起终点）
第二层：跟随动态（衣物/发丝/配饰惯性）
第三层：光线变化（移动中光线如何随空间改变）
第四层：声音连接（环境音从远到近/从静到动）
```

### 双人对手戏调度

两人对话用调度动作（遮挡/观察/靠近/挡路）建立空间关系，不写"两人面对面站立"：

```
遮挡建立位置 → 观察/探查 → 移动/靠近 → 关系结果
```

## 输出格式（与 SKILL.md 一致）

场记表「摄影」列格式：`设备，焦段，机位，镜头运动`

- 以上四项逗号分隔关键词，不超过 15 字
- 焦段仅作倾向，不写精确数值
- 上方景别体系、文戏镜头规则、景别软路径、镜头方位精度均为**判断依据**，不直接写入字段

示例：
- `肩扛，16mm，水平略俯，静镜`
- `手持，50mm，眼平双人，静镜`
- `手持，85mm，POV→过肩`
- `三脚架，35mm，略俯，缓推`
