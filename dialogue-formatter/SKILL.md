# Dialogue Formatter

从剧本中提取并格式化当前 P 段台词，用于场记表「台词」列。

## 输入

当前 P 段的剧本原文，包含对白、OS 或 VO 标注。

## 输出

单一字段值，直接填入场记表「台词」列。格式：保留原文，多句用 `/` 分隔，OS 用括号标注，无台词输出 `—`。

## 权限边界

- 严格保留原文，不改写不删减，不移位任何词
- 台词过长时只在语义节点处加…标注省略，不重新组织句子
- 不填写其他列的内容
- 不增加剧本中不存在的台词

## 输出规则

- 严格保留原文，不改写不删减，不移位任何词
- 多句用 / 分隔
- OS（内心独白/画外音）用括号标注：(OS)内容
- 无台词填 —
- 台词过长时只在语义节点处加…标注省略，不重新组织句子

## 台词类型

| 类型 | 格式 |
|------|------|
| 普通对白 | 原文 |
| 内心独白 OS | (OS)原文 |
| 画外音 VO | (VO)原文 |
| 多人对白 | 甲台词 / 乙台词 |

## 参考

## 示例

| 输入 | 输出 |
|------|------|
| 苏老太惊喜喊：野菜！有救了！ | 野菜！有救了！ |
| 苏老太OS：完了……我死了，大强他们可怎么办！ | (OS)完了…大强他们可怎么办！ |
| 苏老太：我能用这个换您一个包子吗？老板：这是包子铺不是典当铺 | 我能用这换包子吗？/ 这是包子铺不是典当铺 |
| 纯动作节拍，无台词 | — |
