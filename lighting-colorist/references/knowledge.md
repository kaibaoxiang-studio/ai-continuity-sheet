# 灯光色卡字段规则

来源：jimeng-storyboard-v3/references/state-continuity.md + cinematic-lighting.md

## 最小光源锚点（四项必填）

每个 Prompt 必须建立可执行的最小光源锚点，四项缺一不可：

1. **真实来源**：窗户自然光、门外天光、顶灯、壁灯、灯笼、烛火、火焰或月光等场景中实际存在的光源；不得只写"电影光""氛围光""高级光影"或未说明来源的"主光"
2. **方向**：绑定门窗、灯具、床头/床尾、人物受光侧等可追踪关系；不得只写抽象的"侧光"
3. **质地**：至少说明冷/暖/中性以及柔光/硬光
4. **效果**：自然塑形写"自然明暗塑形，无额外风格化灯光效果"；明确效果从体积光/色彩光/动态光/轮廓分离中选

## 光影结果字段（六项）

```text
💡 光影结果：主体光区=...｜明暗层级=...｜暗部与高光=...｜分离方式=...｜材质响应=...｜移动受光=...
```

| 字段 | 填写规则 |
|------|---------|
| 主体光区 | 逐一说明关键主体处于完整光区/明暗交界/可读逆光/可读暗部/剪影中的哪种状态 |
| 明暗层级 | 说明第一注意力对象，以及主体相对背景更亮/持平/更暗的关系 |
| 暗部与高光 | 阴影侧是否保留表情动作，需要保护的高光不过曝 |
| 分离方式 | 从明暗、冷暖、景深、遮挡中选最少有效方式；新增轮廓光受效果锁约束 |
| 材质响应 | 当前镜头真正重要的一至三种材质的纹理/灰阶/反射是否受控 |
| 移动受光 | 跨光区时写起点/终点/过渡；无跨光区写"不适用，当前光影结果保持稳定" |

## 连续性规则

- 最小光源锚点在每个 Prompt 第一块声明一次
- 后续节拍只在换光区、遮挡光源、开关灯、开门、闪电或其他可见光源事件发生时补写变化
- 没有光源事件时，来源、方向、质地和效果跨节拍保持稳定
- 人物或摄影机移动只改变受光结果，不得无因改变光源身份

## Render-safe 绝对禁令

- 不写整脸"涨得通红"；改写脸颊紧绷、耳根或脖颈局部泛红
- 不写赤红、猩红或实色红眼；改写眼白泛红、布满血丝
- **瞳孔和眼球发光绝对禁止，无例外**：金光、血光、红光、蓝光、冷光、光点、光束和能量不能进入瞳孔、眼白或眼球
- 允许：自然泪光、眼白血丝、眼里映着某人，以及酒渍、血泊等真实红色物体

## 打光类型与适用场景

来源：知识库/导演相关/总导演/灯光导演.html

| 打光类型 | 核心特征 | 适用场景 |
|---------|---------|---------|
| 侧逆光 | 光源在人物侧后方，边缘出现轮廓亮边 | 人物出场、回头、等待、相遇、擦肩 |
| 轮廓光 | 强光从侧后方或背后切出人物边缘 | 夜景/暗背景人物分离、古风女主、战损站位 |
| 暖色轮廓光 | 金色/橙色边缘光 | 温暖、浪漫、命运感场景 |
| 冷色轮廓光 | 蓝色/银色边缘光 | 冷静、神秘、悬疑场景 |
| 侧光（45度） | 一半脸亮一半脸暗 | 独白、秘密揭晓、内心挣扎 |
| 硬光 | 光影边缘清晰锐利 | 商业广告、产品展示，不适合情感近景 |

**关键原则**：
- 主光与补光必须分层写：主光负责氛围和明暗结构，补光负责保留面部细节，不能混写为"均匀照亮"
- 任何人物近景/特写中，眼神光必须单独声明（"清晰眼神光"），不会从主光自动产生
- 大光比暗部字段不写"死黑"，需补"保留皮肤纹理、五官结构和材质细节"
- 色温需显式写入：暖色侧光对应古风内室/情感戏；冷色侧光对应悬疑/反转/揭秘场景
- 体积光/神明光需同时声明"空气中有轻微烟雾/雾气"作为光束可见的物理条件（仅明确效果模式可用）

## 场记表「灯光/色卡」列输出格式（与 SKILL.md 一致）

格式：`光源方向，色调关键词`，不超过 10 字。同场景延续且无变化时输出 `同上`。

上方最小光源锚点四项、光影结果六字段、打光类型表均为**判断依据**，不直接写入字段。

示例：
- `侧逆光，冷蓝`
- `顶光，焦黄偏白`
- `散射光，暖黄柔和`
- `侧光，暗褐低饱和`
- `同上`
