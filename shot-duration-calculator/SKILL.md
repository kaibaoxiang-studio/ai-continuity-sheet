# Shot Duration Calculator

计算当前 P 段的估算时长，用于场记表「时长」列。

## 输入

当前 P 段的台词文字（字数）和动作描述（复杂度），以及使用的模型（Seedance 2.0 / 2.5）。

## 输出

单一字段值，直接填入场记表「时长」列。格式：`Xs`（如 `8s`）。

## 权限边界

- 只做时长估算，不修改台词或动作内容
- 超过模型上限时输出上限值并标注"建议拆P"，不自行拆分
- 不填写其他列的内容

## 计算公式

基础公式：**4 字 = 1 秒**

时长 = max(台词时长, 动作时长)

台词时长 = 台词字数 ÷ 4（秒）
动作时长 = 动作节拍数 × 2-3 秒（视复杂度）

## 时长边界（Seedance 2.5）

- 最短：4 秒
- 标准范围：4-23 秒
- 复核区：24-30 秒（人工复核）
- 超限：>30 秒必须拆 P

## 动作时长参考

| 动作类型 | 估算时长 |
|---------|---------|
| 单一表情变化 | 2-3s |
| 简单肢体动作 | 3-5s |
| 复合动作序列 | 5-8s |
| 激烈动作/坠落 | 6-10s |
| 空镜/环境建立 | 4-6s |

## 示例

| 输入 | 计算过程 | 输出 |
|------|---------|------|
| 台词"野菜！有救了！"（5字），简单动作 | max(5÷4≈2s, 3s)=3s → 补足最低4s | 4s |
| OS 20字 + 坠落动作 | max(20÷4=5s, 7s)=7s | 7s |
| 纯空镜，无台词 | 动作时长 5s | 5s |
| 对话 30 字 + 简单动作 | max(30÷4=8s, 4s)=8s | 8s |
