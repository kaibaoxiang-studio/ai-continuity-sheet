# 时长计算字段规则

本文件规则已内置，独立可用，无需安装其他 skill。

## 基础时长公式

```text
中文台词时长 = 有效汉字数 ÷ 4
英文台词时长 = 英文口播词数 ÷ 2.5
中英混合台词时长 = 中文部分时长 + 英文部分时长
节拍时长 = max（台词时长，并行动作时长）+ 静默停顿 + 转场成本
P 段预算 = 所有节拍时长之和
```

**关键原则**：台词与动作同时发生时取较大值，不重复相加。

## 动作估值参考表

| 动作类型 | 建议预算 |
|---------|---------|
| 瞳孔变化、抿唇、呼吸一顿 | 0.3-0.8 秒 |
| 抬眼、低头、转头、握紧或松开 | 0.5-1 秒 |
| 起身、坐下、转身、拔剑、收剑 | 1-2 秒 |
| 走近一至三步、从画外入画 | 1.5-3 秒 |
| 接物、递物、拥抱、推开 | 1-2.5 秒 |
| reaction 迟滞、情绪停顿 | 0.5-1.5 秒 |
| 普通硬切 | 0-0.2 秒 |
| 渐暗、叠化、黑场停顿 | 0.5-1.5 秒 |

## 机器可读预算行格式

```text
节拍1：台词=1s｜动作=1.5s｜停顿=0.5s｜转场=0s｜小计=2s
节拍2：台词=0s｜动作=3.8s｜停顿=0s｜转场=0.2s｜小计=4s
⏱ P01 时长预算：可用=8s｜节拍合计=6s｜自然余量=2s
```

- `小计 = max（台词，动作）+ 停顿 + 转场`
- 所有节拍小计之和必须等于 `节拍合计`
- `自然余量 = 可用 - 节拍合计`
- `可用` 必须等于 SC/P 标题声明时长

## 模型时长限制

| 模型 | 单次时长范围 |
|------|------------|
| Seedance 2.0 | 4-15 秒 |
| Seedance 2.5 | 4-30 秒（内测灰度） |

## 场记表「时长」列输出格式

- 填写秒数，例如 `8s`、`12s`、`6s`
- 必须有明确秒数，不填范围（不写"6-8s"）
- 不超过所用模型单次最大时长
- 不低于 4 秒（模型最小生成时长）

## 拆 P 判定条件

满足任一条件时必须拆 P：

- 预算总时长超过当前模型上限
- 当前 P 台词总量估算超过 12 秒
- 节拍数量超过当前模式上限（文戏/情感戏每 P 不超过 7 节拍，打戏不超过 8 节拍）
- 动作链无法在当前时长内完整呈现

选择切点时优先使用可观察终态：落地、停步、格挡完成、持物稳定、情绪落点完成或镜头急刹。
